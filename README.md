# Facundo Aldorino

## Pagina E-commerce

Desarrollé una tienda web para una casa de repuestos de autos de Villa Ballester. Los clientes pueden buscar una pieza por código o por marca del auto, consultar si es compatible y armar un pedido por WhatsApp.

También creé un panel para que el negocio pueda actualizar los precios desde las listas de Excel de sus proveedores y descontar stock al registrar una venta.

[Visitar la tienda de Repuestos Lamadrid](https://repuestoslamadrid.com.ar/)

## E-commerce con microservicios

Con dos compañeros desarrollé el backend de una tienda como trabajo práctico de Arquitectura y Diseño de Software. Construimos cinco API REST con ASP.NET Core 10 para gestionar productos, usuarios, pedidos, carritos y notificaciones.

Me encargué del [carrito de compras](https://github.com/Fabrimonopoli/Grupo22_CAI/tree/main/Cart.API), que consulta el catálogo para validar el stock, y del [servicio de notificaciones](https://github.com/Fabrimonopoli/Grupo22_CAI/tree/main/Notifications.API), que registra y simula el envío de avisos por correo, SMS y notificaciones push.

[Ver el proyecto del Grupo 22 y su diagrama de arquitectura](https://github.com/Fabrimonopoli/Grupo22_CAI)
