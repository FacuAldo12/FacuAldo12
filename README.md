# Facundo Aldorino

## Repuestos Lamadrid

Desarrollé una tienda web para una casa de repuestos de autos de Villa Ballester. Los clientes pueden buscar una pieza por código o por marca del auto, consultar si es compatible y armar un pedido por WhatsApp.

También creé un panel para que el negocio pueda actualizar los precios desde las listas de Excel de sus proveedores y descontar stock al registrar una venta.

[Visitar la tienda de Repuestos Lamadrid](https://repuestoslamadrid.com.ar/)
